# Sistem Logistik & Katalog Alat 

Aplikasi web untuk manajemen logistik, peminjaman, serta pemeliharaan peralatan outdoor kegiatan mahasiswa pecinta alam.

## Fitur Utama
- **Dashboard Summary:** Monitoring total alat, kondisi layak pakai, perlu perbaikan, dan status dipinjam.
- **Katalog & Inventaris:** Pengelompokan alat berdasarkan divisi (Gunung Hutan, Panjat Tebing, Caving, Sekretariat).
- **Manajemen Peminjaman:** Pencatatan form pinjam, peminjam, jaminan KTP, dan kondisi minus awal.
- **Checklist Ekspedisi:** Pengorganisasian daftar bawaan alat per kegiatan/PIC.
- **Log Perawatan:** Catatan riwayat servis/perbaikan beserta biaya dan penanggung jawab.
