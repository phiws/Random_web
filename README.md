# Birthday Scrapbook Web

Web-based interactive digital scrapbook built for a special birthday celebration. Completely frontend-only and integrated with Formspree for message submissions (no backend database required).

## Features
* **Interactive Flipping Book Layout**: Smooth page-by-page turning experience.
* **Typewriter Effect**: Dynamic animated greetings.
* **Built-in Music Player**: Background audio support ("one song.mp3").
* **Formspree Integration**: Secure and seamless visitor replies/messages directly to email without PHP or Supabase dependencies.

## Tech Stack
* **HTML5**
* **CSS3** (Custom Styling & Animations)
* **JavaScript** (Vanilla JS for interactive book mechanics & form handling)
* **Formspree** (Form backend handling)

## Quick Start
1. Clone or download this branch.
2. Make sure `index.html`, `style.css`, `script.js`, and `one song.mp3` are in the same root directory.
3. Open `index.html` directly in your browser or run it via a local development server (like Live Server in VS Code).
